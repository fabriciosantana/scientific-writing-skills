# Skill: Redação Científica para Codex

## 1) Planejar estrutura IMRaD

**Objetivo:** organizar o artigo em Introdução, Métodos, Resultados e Discussão.

**Prompt base (Codex):**

```text
Atue como editor científico. Com base no tema "[TEMA]" e na pergunta de pesquisa "[PERGUNTA]", crie um esqueleto IMRaD com:
- objetivo de cada seção;
- 3-5 tópicos por seção;
- riscos de escrita (ex.: afirmações sem evidência, falta de coesão).
Use linguagem acadêmica clara em português.
```

## 2) Revisar clareza e concisão

**Objetivo:** melhorar legibilidade sem perder precisão técnica.

**Prompt base (Codex):**

```text
Revise o texto abaixo para redação científica:
[TEXTO]

Requisitos:
- manter sentido original;
- reduzir frases longas e ambiguidades;
- remover redundâncias;
- sugerir versão final e lista breve do que foi melhorado.
```

## 3) Escrever resumo e versão em inglês

**Objetivo:** produzir resumo estruturado e objetivo.

**Prompt base (Codex):**

```text
Escreva um resumo científico (150-250 palavras) com base nas informações:
- Contexto: [CONTEXTO]
- Objetivo: [OBJETIVO]
- Método: [MÉTODO]
- Resultados principais: [RESULTADOS]
- Conclusão: [CONCLUSÃO]

Depois, gere uma versão em inglês acadêmico.
```

## 4) Responder revisores

**Objetivo:** estruturar resposta profissional para revisão por pares.

**Prompt base (Codex):**

```text
Monte uma resposta a revisores para os comentários abaixo:
[COMENTÁRIOS]

Formato:
- "Comentário do revisor"
- "Resposta dos autores"
- "Alteração realizada no manuscrito"

Tom respeitoso, objetivo e baseado em evidências.
```

## Checklist final de qualidade

Antes de submeter, validar:
- [ ] Objetivo e contribuição estão explícitos
- [ ] Métodos são reprodutíveis
- [ ] Resultados não repetem discussão
- [ ] Conclusões não extrapolam evidências
- [ ] Texto está claro, conciso e consistente
