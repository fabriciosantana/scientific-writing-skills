# Scientific Writing Skills

Repositório com skills prontas para usar no Codex com foco em redação científica.

## Conteúdo

- `skills/redacao-cientifica.md`: biblioteca inicial de prompts e checklists para escrita científica.

## Uso rápido

1. Abra o arquivo de skill desejado.
2. Copie o prompt base.
3. Preencha os campos do seu trabalho e execute no Codex.
